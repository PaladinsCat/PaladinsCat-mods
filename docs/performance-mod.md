# Performance mod for Paladins Season 8.1 (Win64)

Requires Tempest Launcher.

1. Download and extract the [release ZIP](https://github.com/PaladinsCat/PaladinsCat-mods/releases/latest).
2. Exit Paladins.
3. Run:

```powershell
.\paladinscat-mods.exe --launch --game-root "C:\Paladins\Season 8.1" --language INT
```

Change the game path as needed. Use `--language KOR` for Korean.

## Previous input version

Exit Paladins, then run:

```powershell
.\paladinscat-mods.exe --launch --rollback --game-root "C:\Paladins\Season 8.1" --language INT
```

To remove the mod, launch Paladins without custom DLLs.
