# PaladinsCat performance mod v0.1.0

First public release of the native input and small world-job scheduler mod for the pinned Paladins Season 8.1 Win64 build.

The package combines bounded native message-pump work, fresh per-event modifier snapshots, compact buffering on the existing DirectInput worker and threshold-four native world-job scheduling. The portable Rust launcher verifies immutable game, DLL and Windows-module hashes and passes startup injection options to the installed Tempest CLI in the correct position. A retained raw-read input DLL is included for rollback with the same world scheduler.

Startup activation of the exact input/world DLLs was verified, including initial native input activity without reported read, validation or ownership errors. Scoped candidate tests and the WatchCat project checks passed. The new release launcher and ZIP package are checked independently.

**Performance and full input compatibility are not verified for v0.1.0.** The maintainer chose to skip further recordings and release this version. No sustained 1,000 FPS, frame-stability, FPS improvement or latency claim is made. Rendering adds no cap; 1,000 FPS remains the target. Buffered input timing, control ordering, IME/focus/menu behavior and scheduler gameplay behavior need further validation.

Download the Windows x64 ZIP and verify it against `SHA256SUMS.txt`. The ZIP includes a per-file manifest and checksums. See its `README.md` for compatibility, launch and rollback. Other game or Windows-module builds are refused.
